# House Rent Manager

A simple web app that helps landlords and landladies manage, coordinate, and control their house tenants.

## Features
- Add a house name and resident address, shown at the top of the app
- Manage tenants, rent, and extra charges (electricity, security, agent fee, water)
- Record payments by Opay, bank transfer, cash, or POS
- Tenants can report a payment, and the landlord confirms it
- See who has paid, part paid, or is in default
- One-tap WhatsApp and SMS reminders for tenants who owe
- House rules and regulations section
- Tenant view showing rent, bills, amount owed, and rules

## How to use
Open `index.html` in a browser. Data is saved in the browser (localStorage).

## Limitations
- Data is stored only on the device you use. There is no tenant sign-in or shared database yet.
- Reminders open WhatsApp or SMS with a prepared message. They are not sent automatically.

## Roadmap
- Tenant sign-in with phone OTP
- Shared database (Firebase or Supabase)
- Automatic SMS and WhatsApp reminders
- Online payments with automatic confirmation
